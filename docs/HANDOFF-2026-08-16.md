### Klíčové zjištění k messages (K1) — reverse-engineering proti MCP referenci
Sekvenční zpráva v `t_connector`: `PDATA1` = Synchronous/Asynchronous (Automation `TransitionEvent`), `PDATA2` = `paramsDlgs=;params=<args>;retval=<ret>` (`TransitionGuard`), `PDATA3` = "Call" (`TransitionAction`), `SeqNo` + `DiagramID` zapisovatelné. Návratová zpráva: MCP kóduje `PDATA4=1`, bridge používá `SubType="Return"` — **obojí EA kreslí čárkovaně** a čtecí strana bridge rozumí oběma (viz `FB_OpGetDiagrams`). Každý item response nese `pdata` readback = okamžitá kontrola bez druhého dotazu.
